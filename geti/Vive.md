## Vibe Coding 개념

자연어로 요청 → AI가 코드 생성, 결과물 중심 개발 방식

## AI와 협업하는 개발 방식

방향은 사람이, 구현은 AI가, 검토는 다시 사람이

## AI 코드 검증 방법

직접 실행 테스트, 엣지 케이스 확인, 로직 한 줄씩 이해하고 넘어가기

## 작업 단위(Task) 분리

큰 기능 한 번에 하지 않고, DTO → 검증 로직 → 예외처리처럼 잘게 쪼개서 순서대로 요

## 코드 리뷰 방법

네이밍, 중복 로직, 예외 처리 누락 여부, 왜 이렇게 짰는지 설명 가능한지 체크

## AI의 한계와 환각(Hallucination)

없는 라이브러리·함수를 있는 것처럼 지어내는 현상.

중요한 점 : 그럴듯해도 공식 문서로 재확인 필수

## AI Pair Programming

사람(설계·의도) + AI(타이핑·구현) 실시간 짝 프로그래밍

## AI Code Review

AI가 버그·네이밍·성능 등을 훑고 판단해주는 것

## Multi Agent Workflow

역할별 AI 에이전트 분업 (기획 → 코드 작성 → 테스트 순서로 이어받음)
