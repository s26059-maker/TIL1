## Prompt Engineering 개념

LLM한테 원하는 답을 더 잘 뽑아내려고 프롬프트를 의도적으로 설계하고 다듬는 작업

## 역할(Role) 지정

AI한테 특정 캐릭터/전문성을 씌워서 답변 톤과 깊이를 맞추는 것

## 작업 분할

큰 작업을 여러 단계로 쪼개서 순서대로 시키는 것

## 출력 형식 지정

표, JSON, 불릿 등 답변 모양을 미리 정해주는 것

## 제약 조건 작성

길이, 금지사항, 필수사항 같은 규칙을 거는 것

## 단계별 프롬프트 작성

한 번에 끝내지 않고 대화를 이어가며 답을 다듬는 것

## Chain of Thought 개념 이해

답만 내지 말고 생각 과정을 단계별로 풀어서 쓰게 하는 기법

## Few-shot Prompting

원하는 답변 예시를 몇 개 보여주고 그대로 따라하게 시키는 것

## Template Prompt

자주 쓰는 프롬프트 구조를 틀로 만들어놓고 재사용하는 것

## Prompt Versioning

프롬프트를 v1, v2처럼 버전 관리해서 비교·복원하는 것

## Prompt 최적화 전략

한 번에 완성하려 하지 말고 계속 테스트하며 고쳐나가는 접근법
