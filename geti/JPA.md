## Entity

DB 테이블을 자바 클래스로 만든 것

## Repository

DB와 직접 통신하는 곳

## Persistence Context

DB에 바로 접근하지 않고, 엔티티를 잠시 보관하는 공

## Dirty Checking

영속성 컨텍스트가 관리하는 엔티티의 변경을 감지하여, 트랜잭션 종료시 자동으로 수정한다.

## Transaction

쪼개면 안 되는 작업 한 덩어리

모두 성공하면 COMMIT, 1개라도 실패하면 ROLLBACK하는 기능이다.

## Fetch

연관된 데이터를 언제 가져올지 정하는 방식

- 즉시조회
- 지연 로딩

## Cascade

부모 엔티티의 작업을 자식에게도 전파하는 기

## 연관관계

엔티티의 연결 관계를 의미

ERD 설계한 것 같이 

- 일대일
- 일대다
- 다대일
- 다대다

같은 관계가 있다

## EntityGraph

지연로딩을 유지하면서 조회할 때 필요한 연관 데이터만 함께 가져오라고 지정하는 기능

## Lock

여러 사용자가 동시에 같은 데이터를 수정할 때 충돌이 발생하지 않도록 데이터를 잠그는 기능이다
