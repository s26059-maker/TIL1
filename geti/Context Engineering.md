## Context Engineering 개념

AI가 좋은 답을 내도록 필요한 정보를 잘 구조화해서 넣어주는 작업

## AGENTS.md

AI 에이전트가 프로젝트 다루는 방법을 정의한 표준 문서

## CLAUDE.md

Claude Code가 프로젝트 시작 시 자동으로 읽는 컨텍스트 문서

## 프로젝트 규칙 작성

네이밍 규칙, 폴더 구조, 금지 패턴 등을 문서화해서 AI가 일관되게 따르도록 함

## 아키텍처 문서 작성

레이어 구조, 모듈 간 의존 관계, 주요 컴포넌트 역할을 정리해서 AI가 전체 그림 이해하게 함

## Coding Convention 문서

들여쓰기, 네이밍, 주석 규칙 등을 명시해 AI 생성 코드도 팀 스타일에 맞추기

## AI에게 프로젝트 컨텍스트 제공 방법

관련 파일만 선별해서 넣기, 문서 요약본 활용, 이전 대화·결정사항 요약해서 전달

## MCP(Model Context Protocol)

AI가 외부 도구·데이터(DB, API, 파일 등)에 표준화된 방식으로 접근하게 해주는 프로토콜

## Agent Workflow

AI가 계획 수립 → 실행 → 검증 → 수정을 반복하며 작업을 자율적으로 진행하는 흐름

## 프로젝트 문서 자동화

코드 변경 시 문서를 AI가 자동으로 갱신하도록 하는 방식
