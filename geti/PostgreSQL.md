## PostgreSQL 특징

MySQL보다 기능 많고 복잡한 거 잘하는 RDB

- Materialized View: 쿼리 결과를 저장해두는 뷰
- RETURNING: 쓰기(INSERT/UPDATE/DELETE) 하면서 결과값을 바로 받는 기능
- 트랜잭션 DDL: 테이블 구조 변경(ALTER 등)도 롤백 가능

## Schema

DB 안에서 테이블을 묶는 폴더

정리가 잘되고 권한 분리에 유리함, 이름도 다른 스키마면 중복으로 쓸 수 있음

## JSONB

바이너리로 변환해서 저장하는 타입

### 바이너리

```jsx
[헤더: 키 2개짜리 객체다]
[키 목록: name, age]         ← 키가 정렬돼서 저장됨
[값 위치: name→0번지, age→8번지] ← 어디 있는지 주소표
[값: "정성원"] [값: 17]        ← 17은 문자 "17"이 아니라 진짜 숫자로
```

글자 대신 [헤더+키목록+주소표+값] 구조로 저장

## Index

값을 정렬해서 위치와 함께 저장하는 것

조회 빨라지지만 쓰기 느려지고 공간 먹으니 자주 검색하는 컬럼에만 사용하자.
